## 🚀 How to Host on GitHub Pages

1. Create a new GitHub repository (e.g. `369-manifestation`).
2. Upload all files from this folder (`index.html`, `manifest.json`, `sw.js`, `.nojekyll`, `css/`, `js/`, `icons/`).
3. Go to **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: `main` / `/(root)` → **Save**.
4. In 1 minute, your app is live at: `https://<your-username>.github.io/<your-repo-name>/`.

---

## 📱 How to Pin Like an APK on Android

1. Open `https://<your-username>.github.io/<your-repo-name>/` in **Google Chrome** on your Android phone.
2. Tap the **three dots menu (⋮)** in the top right corner.
3. Tap **“Install app”** (or **“Add to Home screen”**).
4. Tap **Install**.
5. The 369 icon will now sit on your home screen and open full-screen just like an APK app!
